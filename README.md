# PulseFit Gym Management System

A responsive gym operations dashboard built with React, TypeScript, Vite, Tailwind CSS, and Lucide icons.

## Included in this version

- Dashboard overview with revenue, attendance, classes, and membership metrics
- Member directory with search, add-member form, and remove action
- Class schedule management view
- Attendance/check-in dashboard
- Billing plans and upcoming payment view
- Reports and business metrics view
- Responsive layout with seeded demo data

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

This is currently a frontend demo using local state. A production deployment should connect the member, payment, authentication, and attendance flows to a secure backend/database.
